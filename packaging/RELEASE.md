# Releasing IPTV TUI (GitHub + AUR)

Mirrors the `heimdall-hub-bin` flow. Two AUR packages are provided:

- **`iptv-tui`** — builds from the tagged source tarball (`makedepends=go`).
- **`iptv-tui-bin`** — installs prebuilt per-arch binaries from the GitHub release.

Both install the binary as **`/usr/bin/iptv-tui`** and a man page; they
`provides`/`conflicts` each other. License: **AGPL-3.0-or-later**.

## Prerequisites (one-time)

- GitHub repo `github.com/kinncj/iptv` (the module path already matches).
- `gh` authenticated (`gh auth status`).
- AUR SSH configured (same as heimdall): an `aur` remote over `ssh://aur@aur.archlinux.org/…`.

## 1. Tag and push the source

```bash
cd ~/.iptv
git init -b main                 # if not already a repo
git add -A && git commit -m "iptv-tui v1.3.0"
git remote add origin git@github.com:kinncj/iptv.git   # if missing
git push -u origin main
git tag v1.3.0 && git push origin v1.3.0
```

## 2. Build release binaries and publish the GitHub release

```bash
make release VERSION=1.3.0       # -> dist/iptv-tui_linux_{amd64,arm64} + iptv-tui.1
gh release create v1.3.0 \
  dist/iptv-tui_linux_amd64 \
  dist/iptv-tui_linux_arm64 \
  dist/iptv-tui.1 \
  --title "IPTV TUI v1.3.0" --notes "See README."
```

## 3. Generate the -bin PKGBUILD with real checksums

```bash
./packaging/aur/gen-pkgbuild.sh 1.3.0     # fills sha256sums from dist/
```

This rewrites `packaging/aur/iptv-tui-bin/{PKGBUILD,.SRCINFO}`.

## 4. Push to the AUR

For each package (`iptv-tui-bin` first; `iptv-tui` is optional):

```bash
# clone the (empty) AUR repo once:
git clone ssh://aur@aur.archlinux.org/iptv-tui-bin.git /tmp/aur-iptv-tui-bin
cp packaging/aur/iptv-tui-bin/PKGBUILD packaging/aur/iptv-tui-bin/.SRCINFO /tmp/aur-iptv-tui-bin/
cd /tmp/aur-iptv-tui-bin
# sanity check locally:
makepkg --printsrcinfo > .SRCINFO      # regenerates .SRCINFO from PKGBUILD
namcap PKGBUILD                        # optional lint
git add PKGBUILD .SRCINFO
git commit -m "iptv-tui-bin 1.3.0"
git push
```

For the source package, regenerate its `.SRCINFO` too:

```bash
cd packaging/aur/iptv-tui && makepkg --printsrcinfo > .SRCINFO
```

## 5. Verify

```bash
makepkg -si            # in the package dir, installs locally
iptv-tui -themes       # smoke test
man iptv-tui
```

## Cutting the next version

Bump `VERSION`, repeat steps 1–4. The `-bin` PKGBUILD is always regenerated by
`gen-pkgbuild.sh`; the source PKGBUILD just needs its `pkgver` and `.SRCINFO`
updated (tarball `sha256sums=('SKIP')` is fine for GitHub archive tags).
